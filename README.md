# DolanGan

Latihan landing page statis untuk situs tur/wisata bernama "DolanGan" (konten masih berupa teks *lorem ipsum* dan data tur contoh), di-host dengan GitHub Pages.

## Isi Halaman
Home, About, Services, Featured Tours, Gallery, Footer.

## Tech Stack
HTML, CSS, JavaScript (`js/app.js`: toggle navbar, navbar tetap saat scroll, smooth scroll), Font Awesome. `_config.yml` mengatur tema Jekyll `jekyll-theme-cayman` untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `css/` — `style.css` dan Font Awesome
- `js/app.js` — skrip halaman
- `img/` — gambar latar, logo, foto tur

## Menjalankan
Buka `index.html` langsung di browser.
